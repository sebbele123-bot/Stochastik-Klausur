Teil A · Maximum-Likelihood-Schätzer

Rezept 1 — der klassische Weg (so machen es T5 und T6)
1. Likelihood aufstellen: L(θ) = ∏i=1n f(xi; θ)
2. Logarithmieren: l(θ) = ∑ ln f(xi; θ)  (Produkt → Summe)
3. Ableiten und null setzen: l′(θ) = 0  →  nach θ auflösen
4. Maximum prüfen: l″(θ) < 0 ✓
Beispiel Poisson (Pre-Klausur Aufgabe 1c). f(x;θ) = e−θθx/x!
1. Likelihood:
L(θ) = ∏ e−θθxixi! = e−nθ θΣxi∏ xi!
2. Logarithmieren:
l(θ) = −nθ + (∑xi) ln θ − ∑ ln(xi!)
3. Ableiten, null setzen:
l′(θ) = −n + ∑xiθ = 0  ⇒  θ̂ = ∑xin = x̄
Der letzte Term hat kein θ, fällt also beim Ableiten weg.
4. Maximum? l″(θ) = −(∑xi)/θ2 < 0 ✓  →  θ̂ = x̄, das arithmetische Mittel.
Rezept 2 — der Abkürzungsweg (Satz 60)

Steht die Verteilung schon als Exponentialfamilie da (Lektion 4), geht es ohne Ableiten. Satz 60 sagt: löse einfach

Eθ[T(X)] = T(x)

Für n i.i.d. Poisson ist T(x) = ∑xi und Eθ[∑Xi] = nθ, also nθ = ∑xi ⇒ θ̂ = x̄ — dasselbe Ergebnis in einer Zeile.

Welchen Weg in der Klausur?

Steht „mithilfe von Satz 60" in der Aufgabe → Rezept 2. Sonst → Rezept 1 (immer sicher, funktioniert auch außerhalb von Exponentialfamilien). Beide können, ist die sicherste Vorbereitung.

Zweites Beispiel: Exp(λ) — kommt in T5 und T6 vor, also gut merken.
L(λ) = ∏ λe−λxi = λne−λΣxi
l(λ) = n ln λ − λ∑xi  ⇒  l′ = nλ − ∑xi = 0
⇒ λ̂ = n∑xi = 1x̄
Merksatz: Poisson → x̄,  Exponential → 1/x̄.

Teil B · Der Gauß-Test

Das Testschema — immer diese 4 Schritte
1. Teststatistik unter H0:  Z = X̄ − µ0σ/√n  ~ N(0,1)
2. Kritischer Bereich je nach Gegenhypothese:
H1: µ > µ0 → verwerfen falls Z > z1−α
H1: µ < µ0 → verwerfen falls Z < −z1−α
H1: µ ≠ µ0 → verwerfen falls |Z| > z1−α/2
3. Vergleichen und entscheiden.
4. p-Wert (falls gefragt): einseitig p = 1 − Φ(z), zweiseitig p = 2(1 − Φ(|z|)). Verwerfen ⇔ p < α.
Pre-Klausur Aufgabe 2. X1,…,X25 i.i.d. N(2µ, 9), beobachtet x̄ = 0,8. Teste H0: µ = 0 gegen H1: µ > 0, α = 0,05.
⚠ Der Trick dieser Aufgabe: Der Erwartungswert ist 2µ, nicht µ. Unter H0: µ = 0 ist 2µ = 0 — das passt hier zufällig, aber beim Konfidenzintervall wird es gleich entscheidend.
1. Streuung von X̄: σ2 = 9, also σ = 3, n = 25:
σ/√n = 35 = 0,6
2. Teststatistik:
Z = 0,8 − 00,6 = 1,33
3. Vergleich: einseitig nach oben, also gegen z0,95 = 1,645:
1,33  <  1,645
⇒ H0 wird nicht verworfen. Die Daten liefern keinen ausreichenden Beleg für µ > 0.
4. p-Wert: p = 1 − Φ(1,33) ≈ 1 − 0,908 = 0,09. Wegen 0,09 > 0,05 ebenfalls: nicht verwerfen ✓ Zwei Wege, dieselbe Entscheidung — gute Kontrolle.

Teil C · Konfidenzintervall

Die Formel
X̄ ± z1−α/2 · σ√n

Für 95 %: z0,975 = 1,96.  (Nicht 1,645 — das ist der einseitige Wert!)

Fortsetzung der Aufgabe. Erst das Intervall für 2µ, denn das ist der Erwartungswert von X̄:
0,8 ± 1,96 · 0,6 = 0,8 ± 1,176 = [−0,376 ;  1,976]
Jetzt durch 2 teilen — gesucht war µ, nicht 2µ:
µ ∈ [−0,188 ;  0,988]
Genau hier verlieren die meisten den Punkt. Immer fragen: Wonach war gefragt?
Verträglich mit Teil (a)? Ja: Die 0 liegt im Intervall, also ist µ = 0 mit den Daten vereinbar — passt dazu, dass H0 nicht verworfen wurde. ✓ (Streng genommen gehört zum zweiseitigen Intervall ein zweiseitiger Test; die Schlussfolgerung ist hier trotzdem konsistent — genau das will die Aufgabe hören.)
Die drei Fehler, die morgen Punkte kosten
① z1−α und z1−α/2 verwechseln. Test einseitig → 1,645. Intervall (95 %) → 1,96.
② √n vergessen. Es heißt σ/√n, nicht σ.
③ Rücktransformation vergessen: gefragt war µ, gerechnet wurde mit 2µ.
